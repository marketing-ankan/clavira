## Config shape

All 43 share the same orientation — the supplier models rings with the hole already on Y:

```php
'<product-slug>' => [
    'mode'   => 'finger',
    'render' => '3d',
    'model'  => '/models/tryon/20-10002l.glb',
    'model_rotation' => [0, 0, 0],
    'real_mm' => 23.1,   // outer diameter, sizes it against the wearer's hand
    'hole_mm' => 16.5,   // finger hole, sizes the occluder that hides the far side
],
```

## Earrings

The 21 pieces in `Loat - 01-Earring` convert cleanly but are **not** listed here. An earring
is not a loop, so there is no hole to measure and nothing for the geometry to key on — where
it hangs from the lobe is a judgement only a person can make. They need `mode => 'ears'`
with a hand-set anchor, the same as the existing PNG pieces.
